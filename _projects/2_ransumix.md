**Ransumix** (from the Indonesian *ransum*, feed ration) is a web app that formulates the cheapest feed ration for beef cattle. Given an animal's body weight and a target daily weight gain, and the prices of the feeds available to the farmer, it finds the least-cost mix that still meets the nutrient requirements.

It combines a Hybrid Modified Evolution Strategies algorithm with Linear Programming, and it checks the result against the nutrient requirements of the NRC (2000) standard. The interface is available in Indonesian and English.
